How It Works

1

Upload JSON with player database or use the template

2

Select Players who are available for this match

3

Choose Teams - 2 or 4 team configuration

4

Algorithm distributes best 1st position choice players first by value and rank, then moves to 2nd position with stamina considerations

Player Properties:

• 1st position Choice: Primary position (e.g., Striker, Midfielder, Defender)

• 1st position Value: Skill level in primary position (1-10)

• 1st position Rank: Ranking in primary position (1=best)

• 2nd position Choice: Secondary position (optional)

• 2nd position Value: Skill level in secondary position (1-10)

• 2nd position Rank: Ranking in secondary position (1=best)

• Stamina: Physical fitness level (1-10 scale)
